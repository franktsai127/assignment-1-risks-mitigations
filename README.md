# Individual Assignment 1: Risks and Mitigations

## Overview

This project contains an LLM-assisted risk analysis for an ML-enabled dashcam system designed to help locate missing children.

## Setup

Setup instructions will be added here.

## Usage

The workflow includes:

1. Generate stakeholders.
2. Review and modify stakeholders.
3. Generate stakeholder goals, losses, and requirements.
4. Review results.
5. Generate assumptions and specifications.

## Files

- `goals.md`: Goals and measurements
- `analysis_results.md`: Full risk analysis
- `key_results.md`: Four curated findings
- `fault_tree.md`: Fault tree analysis and mitigations
- `code/`: LLM automation scripts
- `data/`: Intermediate generated data
- `figures/`: Fault tree images
